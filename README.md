# Cypress API Automation

## Setup Instructions

Install the project dependencies:

```bash
npm install
```

## **Running Tests**

### **Run Cypress Tests**

#### **Interactive Mode (Opens Cypress GUI)**

Navigate to the test cases and execute them in UI mode

```sh
npx cypress open
```

#### **Run Cypress Tests in CLI**

Executes tests in headless mode

```sh
npx cypress run
```
